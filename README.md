
# AI/ML 20-Day Training

## Overview
A hands-on training project covering Python,
data analysis, machine learning, computer vision,
model evaluation, and API development.

## Day 1: Python Project Setup and Git
The first task is a command-line program that reads
a sample CSV file and reports the number of data rows.

## Project Structure

```text
ai-ml-20-day-training/
├── data/
│   └── sample.csv
├── src/
│   └── main.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Requirements
- Python 3.10 or newer
- Git

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

## Run the Program

From the project root:

```powershell
python src/main.py
```

Expected output:

```text
CSV file: sample.csv
Total data rows: 4
```

## Day 1 Learning Outcomes
- Python project structure
- Functions and type hints
- CSV file handling
- Exception handling
- Git version control
